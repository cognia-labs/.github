# Cognia Labs identity

Created: 2026-10-21.

## Profile brief

- Audience: developers and contributors exploring the Cognia ecosystem.
- One-sentence value: one workspace for agents, tools, and knowledge.
- Primary proof: the existing public Cognia source, CLI, SDK, extension, and services.
- First action: explore the main Cognia repository.
- Visual theme: a connected, open C with a calm technical finish.

## Avatar

The open C combines cyan and lavender ribbon faces to represent connected agents,
tools, and knowledge. The silhouette has enough negative space for small avatars
and leaves margins for a circular crop. It is an organization mark; the existing
Cognia application icon is unchanged.

- Background: midnight navy, directed as `#0A1428`.
- Primary: icy cyan, directed as `#64DFF0`.
- Secondary: pale lavender, directed as `#B7BEF5`.
- No text, borders, or fine-line details.

The artwork was generated with the built-in `image_gen` tool. The original is
stored in `assets/cognia-labs-avatar.png`; the 512-pixel upload copy was resized
with macOS `sips`, without changing the composition.

## Generation prompt

Use case: logo-brand. Create a polished, original square GitHub organization avatar for Cognia Labs, an open-source AI workspace and agent tools ecosystem. Brand direction: thoughtful technical clarity, connected context, calm confidence. One bold abstract C-shaped mark built from three continuous interlocking rounded ribbon segments, expressing agents, tools and knowledge coming together in one workspace. Strong negative space, simple distinctive silhouette, no tiny details. The mark should feel like a purposeful connected loop, not a generic atom, brain, hexagon, robot, code brackets, or corporate network diagram. Opaque deep midnight navy background (#0A1428), luminous icy cyan (#64DFF0) main mark with a restrained pale lavender (#B7BEF5) secondary face, clean crisp edges and subtle satin dimensionality, almost flat, no bloom or glow. Center the mark at roughly 65% of canvas width with generous safe margins for GitHub's circular crop. Exceptional legibility at 32px and 64px. No text, no letters spelled out, no border, no watermark, no extra objects. Deliver exactly one finished square avatar, not a mockup, not a collage or contact sheet.
